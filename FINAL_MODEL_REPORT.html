1. 데이터와 검증 계약

2020–2024만 학습하고 2025를 한 번 예측했다. 선수 자격은 2021–2025 매년 공식 선발 20경기 이상이다. q33/q67과 전처리 통계는 모두 2024년까지의 학습 데이터에서 계산한다.

선수 자격 확인에는 2025 출전 여부가 사용되므로 완전한 사전 배포 시뮬레이션은 아니다. 다만 2025 Stuff+ 결과값은 모델 선택이나 학습에 사용하지 않는다.

2. 모델 설정

  • EWMA4: 최근 경기 Stuff+ span 4.
  • Ridge: 선수별 compact16, alpha=100, residual correction scale=0.25.
  • XGBoost: 선수별 compact16, validation trial 16, trees=100, depth=2, residual correction scale=0.221845.
  • TCN: shared causal H1, ordered L=8, channels=4, bottleneck=4, dilation 1/2/4, alpha=0.1, epochs=250, 5 seeds 평균.

네 모델 모두 최종 연속값을 예측 Stuff+ = EWMA4 + 보정 residual 구조로 만든다. TCN은 시간 순서를 학습하고 XGBoost는 비선형 상호작용을 허용하지만, 둘 다 Ridge처럼 계수 하나로 직접 해석할 수는 없다.

  • 등급은 선수별 학습 q33/q67로 나누므로 서로 다른 선수의 Low/Middle/High를 절대 수준처럼 비교하면 안 된다.
  • 같은 예측값이 나오는 경우는 모델이 EWMA 보정을 0에 가깝게 내거나 반올림된 경우이며, 원본 CSV에는 반올림 전 값이 저장된다.
