1. 개요

모든 선수의 반복 패턴은 공통 branch에서, 나머지 전체 피처는 선수별 branch에서 학습했다. 2022~2024 검증으로 설정을 고른 뒤 2025를 고정 평가했다.

2. 데이터와 누수 방지

현재 경기 입력은 사용하지 않는다. 최대 8개의 strictly-prior 등판만 사용하고 대치·정규화는 훈련 구간에서만 적합한다.

5. 모델과 계산식

세 모델 모두 Stuff+를 직접 예측한다. EWMA4는 고정 기준값이 아니라 계수를 학습하는 공통 피처다.

ŷᵢₜ = g(Cᵢₜ, EWMA4ᵢₜ) + hᵢ(Uᵢₜ)

Ridge = 공통 선형 직접 예측 + 선수별 선형 보정
XGBoost = 공통 트리 직접 예측 + 선수별 소형 트리 보정
TCN = 공통 causal encoder + 학습 가능한 EWMA skip + 선수별 선형 보정
이전 식 EWMA4 + 0.1 × 잔차는 사용하지 않는다.

12. 해석·결론

직접예측은 모델 간 차이를 실제 예측값에 반영했고 XGBoost와 TCN의 연속 MAE를 개선했다. 반면 3등급 balanced accuracy는 하락했다. 따라서 연속 Stuff+가 목표면 직접예측 XGBoost, 등급 안정성이 목표면 기존 잔차 방식이 유리하다. Ridge 전체 계수는 CSV로 저장했다.
